# Mission 016 playtest — The Completion Pass

About 20 minutes. Everything here is something you already use; this is about whether it now works the way you expect.
Use the Kamvas where it says so.

## 1. GIF export (4 min)

1. Open one of your own animations on white paper with soft, colourful drawing (best), or **Help › Bouncing ball
   (hand-drawn)**, or insert a reference cycle into a new animation at 100 % opacity.
2. **File › Export animation… › Animated GIF**, save, and open the GIF in a browser.
3. Are the colours the ones you drew? They used to turn slate grey. Look at soft edges and gradients too.
4. Export a pixel-art animation with transparency (**Help › Pixel slime (pixel art)**): the colours should be exact and
   the background transparent.

## 2. Reference picker (2 min)

1. In an animation that already has a reference cycle (or insert one first), **Animation › Insert reference cycle…**.
2. The preview should show only the cycle you pick, on plain paper: no drawings, no earlier reference.
3. Drag in the preview to place the feet, then Insert. Does it land where you dragged?

## 3. Storybook (4 min, Kamvas)

1. Open a storybook. No brush bar, tools, layers dock or timeline should be in the way.
2. Press Delete, Ctrl+V and a few tool keys while looking at a page. Nothing should happen to your drawing.
3. Esc (or **Back to drawing**): everything is back as it was.
4. **Layer › New layer** while the storybook is shown: it should take you back to the drawing and add the layer there.

## 4. Copy to other programs (4 min)

1. Select part of a drawing with a transparent background, Ctrl+C.
2. Paste into the programs you use: Paint, a browser or chat, Office, Paint.NET or GIMP if you have them. Is
   transparency kept where the program supports it? A white background is what programs without transparency get.
3. Back in DoodleNook, Ctrl+V: it should paste in the same place, on a new layer.

## 5. Palettes and sprite sheets (4 min)

1. **Window › Palettes… › Import folder…** with your own palette downloads. Is the summary right? Import the same
   folder again: nothing new should be added.
2. **File › Import sprite sheet…** with a sheet from a game or asset pack you use. Is the first guess right now? If not,
   which sheet (so it can be looked at)?

## 6. Sit down, Stand up, Laughing (2 min)

Insert each from **Animation › Insert reference cycle…** and play it. In Laughing, does the left hand look natural
between slaps? Sitting, do the hands rest on the thighs?

## What to tell me

- Anything that still looks or feels wrong in the six areas above.
- Whether the dialogs fit and read well on the Kamvas at 150 %.
- Pen behaviour on the Kamvas (only you can check that).
